# Burhan research packs

These files are research data and review guidance for detection classes 1–3.
They intentionally contain no detector, payload corpus, oracle, or network
request code. Each source is linked with its license or terms note and the
access date is recorded in the individual file.

Before reuse, an owner must pin source revisions, preserve attribution, and
approve any derived dataset. The packs do not authorize scanning a target or
verifying secrets against a live service.
