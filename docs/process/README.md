# Process records — حزم المحطات

هذا الدليل يودع سجلات العملية التي يأمر المالك بأرشفتها: حزم المراجعة
المستقلة (SPEC §9.5) وعينات المراجعة. كل ملف يحمل تاريخ أمر المالك الذي
أنشأه، ويُقرأ مع SPEC الطبقة المعنية (`download/phaseC/PHASEC-L1-SPEC.md`).

| الملف | المحطة | الحالة |
|-------|--------|--------|
| `owner-order-2026-11-13-REVIEW-PACKAGE.md` | القرارات الخمسة + ملحق أقسى الاختبارات (المحطة «ب») | مودعة للمراجعة المستقلة |
| `owner-order-2026-11-13-SAMPLE-REVIEW-20.md` | عينة المراجعة العشرين (10 قابل للقياس + 10 خارج النطاق) من المرجع المولَّد (116 تسمية) | **بانتظار رد المالك — المرجع غير معتمد** |

قاعدة النسخ: الملف هنا نسخة أرشيفية لحظة الإيداع؛ المصدر الحي يبقى في
حزمة العمل تحت `download/` في مساحة العمل، وأي تحديث لاحق يُودع بملف
جديد مؤرخ لا بتحديث صامت.
